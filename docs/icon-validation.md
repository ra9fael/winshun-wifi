# 图标修复 0.1.2

[English](icon-validation.en.md)

## 问题是什么

ICO 嵌入程序后，原生窗口仍可能使用通用图标。

## 为什么

资源声明不等于窗口图标设置。IDI_ICON1 是字符串资源名。Qt 界面需要显式应用图标资源。

## 改了什么

修复可执行文件图标，补齐打包中的 ICO 和资源脚本。

## 实测

2026-11-09：从提交副本以 MSVC 19.51 / x64 Release 构建；CTest 1/1 通过。资源和真实插件进程检查 16/16 通过（docs/icon-checks.json），含命名资源、8 个尺寸、协议初始化和正常退出。

## 没测的

未自动操作真实任务栏与 Alt+Tab 切换；没有重新验证所有插件功能、硬件路径、跨显示器实际拖动、UAC 安全桌面或全部 Windows 版本。本轮只制作本地标签和安装包，未公开发布。
