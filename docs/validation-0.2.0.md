# v0.2.0 验证记录

日期：2026-11-09。构建：Windows x64，Visual Studio 2026 / MSVC 19.51，Release。

## 自动验证

- ctest：wifi_logic、wifi_qr_native 全部通过。
- 载荷测试覆盖中文、分号/冒号/逗号/引号/反斜线、隐藏网络、开放网络、WEP、WPA3、企业网络、密文与缺失密码、超长输入。
- 原生 PNG 保存、PNG 签名和拒绝覆盖已有文件通过；查询结果不携带密码或二维码载荷，企业/未保存网络不提供二维码动作。
- 原生预览连续打开 3 次，前台窗口与键盘焦点检查通过，Esc 均关闭成功；包含 Windows 未授予前台授权的独立启动场景。
- 剪贴板 CF_DIB 可用；独立 ZXing 解码保存的 PNG 和实际预览窗口截图，均与虚构 WIFI 载荷逐字节一致。

## 范围

二维码数据使用虚构网络名和口令，未保存或记录真实网络密码；没有连接、断开或删除真实 WLAN 配置。未进行手机实际加入网络测试。PNG 与窗口截图由独立的 ZXing 解码器交叉验证，不能替代手机端认证兼容性测试。

使用仓库 tools/package.py 按 v0.2.0 校验并生成 wsplugin 和 SHA-256；GitHub Release 资产附带校验文件。更新安装包后需重启插件以加载新的命令和权限。
