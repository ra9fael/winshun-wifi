# ra9fael.wifi — Win顺 Wi-Fi 管理插件

搜索框直达的 Wi-Fi 管理：查看当前连接与信号、连接/断开、UAC 查看密码、忘记网络、复制配置 XML。纯 native `wlanapi.h`，不解析 netsh 文本。

状态：**规格阶段，代码未实现**。
